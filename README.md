# Gleam - Professional Car Wash Service

## ✨ About Gleam

Gleam is a modern Flutter application that revolutionizes mobile car wash services in Turkey. Users can easily request professional car wash services from their homes or offices, while certified washers can view and accept available jobs.

## 🌟 Features

### 👤 Customer Features
- **Easy Registration/Login**: Phone (SMS) or email authentication
- **Smart Booking**: Address, date, vehicle type and service selection
- **Real-time Tracking**: Live washer location tracking
- **QR Code Verification**: Secure service initiation
- **Rating System**: Rate and review washers
- **Secure Payment**: Safe online payment processing
- **History & Invoices**: Complete booking history

### 🧽 Washer Features
- **Job Opportunities**: View nearby bookings
- **Job Acceptance**: Accept suitable jobs
